Evaluasi Model

Ringkasan Kinerja

R² mendekati 1 berarti prediksi makin tepat. RMSE dan MAE adalah rata-rata kesalahan dalam satuan magnitudo (makin kecil makin baik).

Kesalahan per Rentang Magnitudo

Selisih = rata-rata selisih mutlak. Bias negatif berarti model cenderung memperkirakan lebih kecil dari aslinya, terutama pada gempa besar.

Fitur Paling Berpengaruh

Kesimpulan

  • Model A menjelaskan sekitar 75% variasi magnitudo dan memangkas kesalahan sekitar 50% dibanding baseline. Cocok untuk memeriksa magnitudo di katalog.
  • Model B hanya sedikit lebih baik dari baseline. Magnitudo memang sulit ditebak hanya dari lokasi dan riwayat gempa sekitar.
  • Angka di halaman ini berasal dari pengujian jujur: model dilatih pada 80% data terlama dan diuji pada 20% data terbaru.

Cara Kerja

  • Model dari file .joblib diubah ke JSON dan dijalankan di browser. Hasilnya sama persis dengan scikit-learn.
  • Rentang 90% pada hasil prediksi dihitung dari kesalahan model pada data uji.
  • Jika sumber data tidak bisa dihubungi, aplikasi otomatis memakai data arsip.
Aplikasi ini adalah prototipe akademik, bukan sistem peringatan dini. Informasi resmi gempa dan tsunami hanya dari BMKG.
